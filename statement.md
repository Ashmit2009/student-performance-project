# Student Performance & Grade Analysis System

## Problem Statement

Managing student details and marks manually can be difficult and may cause mistakes.

This project is made using Python to store student details, enter marks, calculate grades, and find the class average.

## Scope

The project covers student details, marks, grades, and basic performance analysis.

## Target Users

- Students
- Teachers

## Main Features

1. Student Management
2. Marks Management
3. Grade Management
4. Performance Analysis
