# Student Performance & Grade Analysis System

## About the Project

This is a simple Python project for managing student details and marks.

The project can store student information, enter marks, calculate grades, and find the class average.

## Features

1. Student Management
2. Marks Management
3. Grade Management
4. Performance Analysis

## Technologies Used

- Python
- VS Code

## How to Run

1. Open the project folder in VS Code.
2. Open `main.py`.
3. Run `main.py`.
4. Select an option from the main menu.

## Project Files

- `main.py` - Main menu of the project
- `student_management.py` - Manages student details
- `marks_manager.py` - Manages student marks
- `grade_calculator.py` - Calculates grade and result
- `performance_analysis.py` - Calculates class average
- `statement.md` - Project statement

## Testing

The project was tested with different student details and marks. Input validation was also added for marks and student information. Enter the marks between 0 and 100.
